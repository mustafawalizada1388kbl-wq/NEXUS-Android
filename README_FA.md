# NEXUS — مرحلهٔ اول

نسخهٔ پایهٔ بومی اندروید با Kotlin و Jetpack Compose، با ظاهر شیشه‌ای و پشتیبانی ابتدایی از دری/فارسی و انگلیسی.

## امکانات پیاده‌سازی‌شده
- داشبورد آینده‌نگر با پنل‌های نیمه‌شفاف و رنگ‌های نئون فیروزه‌ای
- پیمایش میان خانه، دانش، پروژه‌ها، ابزارها و تنظیمات
- تغییر زبان رابط بین فارسی/دری و انگلیسی در همان لحظه
- ساخت، نمایش و حذف یادداشت‌های سریع
- نگهداری یادداشت‌ها در حافظهٔ محلی برنامه با SharedPreferences
- تنظیم روشن/خاموش کردن ظاهر تیره
- گزینهٔ «قفل برنامه» در تنظیمات به‌عنوان تنظیم نمایشی مرحلهٔ اول

## مواردی که هنوز پیاده‌سازی نشده‌اند
- پایگاه دادهٔ ساختاریافته با Room و تنظیمات با DataStore (در حال حاضر یادداشت‌ها با SharedPreferences نگهداری می‌شوند)
- قفل واقعی با PIN یا اثر انگشت
- محتوای واقعی بخش‌های دانش، پروژه‌ها و ابزارها
- آزمایش روی دستگاه فیزیکی و تولید APK نهایی

## نیازمندی‌ها
- Android Studio نسخهٔ جدید
- Android SDK مطابق compileSdk 35
- اینترنت فقط برای نخستین بار، جهت دریافت افزونه‌ها و کتابخانه‌های Gradle؛ خود رابط برنامه پس از نصب برای نمایش به اینترنت نیاز ندارد.

## باز کردن پروژه در ویندوز ۱۱
1. فایل ZIP را استخراج کن؛ مثلاً در پوشهٔ Documents.
2. Android Studio را باز کن.
3. در صفحهٔ آغاز، روی **Open** بزن.
4. پوشهٔ استخراج‌شدهٔ `NEXUS_Android_Phase1` را انتخاب کن.
5. منتظر بمان تا **Gradle Sync** تمام شود. اگر برای نصب Android SDK درخواست آمد، نصبش کن.
6. برای اجرا، یک شبیه‌ساز بساز یا موبایل اندرویدی را با USB وصل کن.
7. دکمهٔ سبز **Run ▶** را بزن و ماژول `app` را انتخاب کن.

## ساخت APK آزمایشی
از منوی Android Studio:
**Build → Build Bundle(s) / APK(s) → Build APK(s)**

اگر ساخت موفق باشد، Android Studio مسیر فایل APK را نشان می‌دهد. معمولاً مسیر این است:
`app/build/outputs/apk/debug/app-debug.apk`

## یادداشت فنی
پروژه عمداً از WebView و HTML استفاده نمی‌کند. رابط کاربری کاملاً بومی و با Jetpack Compose نوشته شده است. این نسخه هنوز مرحلهٔ ابتدایی است؛ یادداشت‌ها به‌صورت محلی نگهداری می‌شوند، اما قفل برنامه فقط گزینهٔ رابط کاربری است و نباید به‌عنوان حفاظت امنیتی واقعی استفاده شود.
